# 头马比赛磨稿教练

把参赛稿发过去，它像一位冠军教练那样跟你聊，陪你一稿一稿把稿子磨好。只给建议，不替你写。

作者：毛斐 Felix

## 它怎么跟你聊

它不交点评报告，它跟你聊天。

- **第一次回复很短。** 它先说它读懂了什么、好在哪里，再问你两件事：这篇是去比赛，还是在例会上讲；你想要“简单反馈”还是“完整报告”。
- **选简单反馈**，它只说最要紧的那一处。
- **选完整报告**，它给你总览和参考分，再盘点稿子的现状，最后给建议。
- **它的建议有依据。** 方法出自哪本 Pathways 手册、手册怎么说，再举一篇大区前三名的演讲，让你看到这个方法做出来是什么样。

它说的都是建议，仅供参考。时长它算不准，要靠你自己计时试讲。

## 它带着什么来

- **五条演讲公理**：演讲是送给观众的礼物，礼物得是你自己的；演讲要有主旨句；演讲一定要聚焦；道理要靠故事送到；普通人也可以讲好故事，贵在真诚。
- **比赛手册**：118 大区普通话演讲比赛的评分标准，以及时长、原创的规则。
- **Pathways 手册要点**。
- **118 大区 2022—2026 年度 19 篇前三名演讲的原稿**。

## 怎么用

在 WorkBuddy 里选中这个技能，然后直接说：

```text
帮我看看这篇稿子。
（下面贴稿子全文）
```

之后就像跟人聊天一样回它。它问你的，照实答；它说的你不同意，直接说，它会和你讨论。

改完之后，把新的一稿再发给它。

## 小提示

- 它追问你的经历时，答案只有你有。它不会替你编，你也别让它编。
- 它只看得到文字。声音、肢体和台风，还要靠真人听你讲。
- 建议都可以不听。稿子是你的，最后由你决定。

## 安装

把整个文件夹放进 WorkBuddy 的技能目录，放好后的位置是：

```text
~/.workbuddy/skills/toastmasters-speech-polish-coach/
```

从 GitHub 下载压缩包的话，解压出来的文件夹名会多一个 `-main`，放进去之前改回 `toastmasters-speech-polish-coach`。
