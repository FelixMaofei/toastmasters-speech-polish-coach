# Pathways 手册：方法在这里

三样经典里，手册是方法，是给建议时最主要的依据。前三名的演讲只是例子，让讲者看到方法做出来是什么样。

## 怎么用

- **给建议之前，先来这里读对应的那本手册。** 不要凭印象引。
- **引的时候说清三样：** 哪本手册，哪一节，它讲的方法是什么。然后再说这个方法用到讲者这篇稿子上，具体该怎么做。
- **这里是要点转述，不是原文。** 用自己的话说，不要加引号当成手册原话。
- 来源：Pathways 精通演讲路径的中文项目手册。L1-2 是 D118 SC 翻译组 2023 年译本，L3 各项目是官方中文版。

## L1-2《撰写有目的的演讲稿》：主题、目的、结构

**撰写你的演讲稿**

- 成功的演讲从一个对讲者自己有意义的话题开始。对自己没什么意义的主题，很难讲得引人入胜。
- 把主题清楚地写下来，写稿时从开头到结尾都紧扣它。
- 动笔前回答三个问题，每一问都只要一件事：
  1. 我想说的最重要的一句话是什么？
  2. 为什么这对观众重要？
  3. 我希望人们在演讲结束很久以后，还记得什么？
- 取舍：5 到 7 分钟装不下所有想说的。每次演讲都要选择怎么用时间。重点一旦清楚，哪些该留、该删、该加就清楚了。
- 基本结构是引言、带过渡的主体、总结。好演讲像一个好故事。
  - 引言：介绍主题，同时引起观众的关注。
  - 主体：每个部分只讲一个想法，并且清楚地过渡到下一部分。
  - 总结：有力地收尾，收拢全文，对观众产生影响。
- 过渡可以用过渡词、短语，也可以用一个场景或时间的描述，把观众带到下一部分。

**组织你的演讲**

手册列了七种组织方式，按内容选：时间顺序；主题和论点；空间；因果；比较；问题与方案；特定—一般—特定（从一个具体例子讲到更大的道理，结尾再回到例子，首尾呼应）。

**定义你的目的**

- 每篇演讲都有一般性目的：告知、说服、娱乐或启发。
- 还要有特定目的：用一句话写出想达成的目标。要从观众的角度写，说清希望他们听完之后能做什么；要现实，做得到。

## L3《故事产生共鸣》：怎么讲好故事

文件名也写作《用故事打动听众》。

**故事的强大作用**

- 讲故事比一般的陈述更容易吸引听众。听众被故事吸引时会有情感反应，情感反应帮助他们记住内容。
- 故事可以是演讲的一个要点，也可以是整篇演讲。怎么放进去，由讲者决定。

**编故事**

- 目的：故事帮讲者和听众建立联系，化解抗拒，把重要的教训或难懂的概念讲明白。
- 语气：故事的语气和情感分寸，要看场合和听众。
- 生动的描述：用词要能在听众脑海里画出画面。同时记着时间，和核心故事无关的细节可以省去，好把核心故事突出出来。
- 对话：不要转述别人说了什么，直接把当时的对话讲出来。
- 大纲：写故事之前先列大纲。
  - 用一句话总结故事的主要观点。
  - 交代背景：时间和地点。
  - 列出人物。
  - 冲突：每个故事都有一个要解决的问题或挑战。手册举了四种：人与自然，两个人之间，人与组织，人与物。
  - 动作：人物怎样努力克服挑战；列出主要事件；有清楚的开场、正文和结尾。

**讲述故事**

- 以第一人称讲。听众和故事里的人离得越近，越觉得故事是真的。
- 把握节奏：激烈处加快，要紧处停顿，适时的沉默很有力量。
- 有对话的地方，排练时用略微不同的语气区分人物。

## L3-1《说服型演讲》：怎么有说服力

**说服的目的和类型**

说服型演讲的目的，是影响观众的想法或行为。有三种，常常一起出现：

- 鼓舞：激发观众对主题的热情，或强化他们已有的看法。
- 使人信服：改变观众的看法。
- 行动号召：希望观众听完之后有所行动。

**如何说服**

- 了解你的主题：透彻研究，从不同角度看问题。
- 三种说服方式，可以同时用，也可以侧重一种：
  - 品德：讲者的可信度。观众先得认可你懂、你可信。可以引用自己的研究，也可以用亲身经历来支撑观点。
  - 逻辑：每个论点都合乎逻辑。清楚、简洁地说明观众为什么要改变，并给出可靠来源的证据。
  - 情感：激起听众的情绪，并把情绪和主题连起来。要改变人的想法，得在理智和情感上都对他有吸引力。
- 了解观众对这个主题的态度，讲法随之不同：本来就赞同的，要强化；无动于衷的，要让他相信这事和他有关；反对的，要讲清观点的价值；不了解的，先让他了解。

**发表你的说服型演讲**

- 讲和主题相关的个人故事和经历，和观众建立联系，唤起共鸣。
- 有行动号召的话，号召要有力，并且明确说出希望观众做什么。

## L3《与听众交流》：怎么和台下的人有关

- 演讲之前先了解听众，才能有针对性地组织和传达信息。
- 看三样：听众的背景特征，已有的知识，价值观和信念。
- 有针对性，不等于把内容改成听众想听的。调整的是措辞和讲法，为的是让听众更好理解、更愿意参与。
- 关注结果：准备时想清楚希望听众有什么收获，并让他们知道这场演讲为什么值得花时间和注意力。
- 可信度：用到外部信息时，给出来源。

## L3《激励你的听众》：怎么打动人

- 激励型演讲的目的，是激励听众在某一方面提升自己。和讲逻辑相比，它更依赖情感上的呼吁。
- 内容可以来自讲者自己的生活：从让自己做出重要改变的几件事里，只选一件。
- 个人的小故事，让主题更直接、更相关。也可以从很多人的共同经历里找内容。
- 感到和讲者有联系的听众，更容易接受讲者说的话。人们记得住自己动情的时刻。
- 保持谦逊，珍惜讲自己故事的机会，更容易和听众建立联系。

## L3《使用描述性语言》：怎么让人看见画面

- 描述性语言用词语描绘画面，帮观众唤起具体的画面来理解观点。
- 字面语言适合直接、明晰地讲事实；比喻性语言适合传达独特的想法，或者产生情感影响。
- 比喻性语言有几种形式：明喻、比喻、象征、夸张、双关。
- 具体细节比模糊细节有力：同一个场面，写出颜色、质地和更准确的动词，听众才看得见。
- 动词选得准，画面就准；形容词补充感官和情感的细节。
- 描述性的词太多，会扰乱核心思想。要适量。

## L3《了解幽默感》：怎么用幽默

文件名也写作《发掘自身幽默感》。

- 幽默的一种形式就是讲故事。再短的笑话，本质上也是一个有开头、中间和结尾的故事。
- 有效的幽默故事有三个要求：有普遍性，大多数人都有过类似经历；简洁；留意时间。
- 讲自己的故事，尤其是大家都有过的经历，往往比事先准备好的笑话效果更好。
- 幽默因人而异。先了解听众，再选故事。
