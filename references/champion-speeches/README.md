# 大区前三名演讲原稿

三样经典之一。这里是 118 大区普通话演讲比赛 2022—2026 四个年度公开发布的 19 篇前三名演讲。它们是标杆：想知道好演讲是怎么做的，就来读原稿，自己体会。

## 怎么用

- 给建议之前，挑和讲者这篇稿子处境相近的一两篇读一读：题材相近，结构相近，或者正好做到了讲者还没做到的那一处。
- 向讲者提到时，说出篇名，说清它是怎么做的，让他知道这条建议有标杆。
- 每篇演讲都是讲者自己的经历。只借做法，不借人物、情节和句子。

## 关于文本

这些文本是现场录音的转写，不是讲者的手稿。

- 2022—2025 三个年度的 12 篇是自动转写，没有逐字校对，有同音错字和漏字。常见的有：“头马”被写成“跑马”“筹码”“头发”，“大区”被写成“大气”，讲者的名字被写成别的字。开头常带着主持人的报幕。
- 2025—2026 年度的 7 篇是转写后的校对稿，没有对照录音复核。
- 拿不准的句子，不要逐字引给讲者，转述它的做法就够了。
